# PRISM 投稿用三指标表

本轮沿用冻结提交 `7bf849fa0c2453ea58412cc631c3cddf9b6d4e3c`、既有评分行和故障注入窗口。四组 TEP、SRU 基准只更新 DPLS 和 GRU。CZ 双棒的基线权重和归档分数继续沿用。

## 表格

- `CLEAN_THREE_METRICS.csv` 汇总集成预测的 RMSE、MAE 和 (R^2)。总平方和使用每个已评分尾段自身的目标均值。RMSE 星号对应相对于 PRISM 的双侧配对检验。符号 `+` 表示基线的配对平方损失较高，`-` 表示较低。
- `FAULT_THREE_METRICS.csv` 汇总 512 点振荡和四倍标准差常量偏置的 RMSE、MAE 和输出偏移 MAE。偏移相对于同一模型在同一窗口的干净预测。
- `DM_HAC_HOLM.csv` 按数据组和工况分别对九项 Bartlett HAC 配对检验做 Holm 校正。极小的概率可读 `log10_p_holm`。
- `IEEE_TABLES.tex` 可用 `\input` 导入双栏稿件。其中三张干净表将同一过程的两个协议并排，六张压力表各自并排展示两类故障。

## 复核口径

扩大后的候选在原有两个训练段前向验证折中选参。DPLS 的潜变量路径和 GRU 的验证轨迹见各组拟合回执。GRU 用前向验证折的池化损失做早停，再按选中的轮次在合格训练行上重估原有五个种子。重新评分前绑定两条基线的拟合回执和 PRISM 的冻结权重。

现有发布归档包含指标与检验统计。为获得两条新增配对检验所需的逐点损失，公开四组回放原 PRISM 冻结权重，并核对与归档 RMSE、MAE 和逐行索引哈希一致。旧表中的 PRISM 指标直接保留。CZ 仅从本地读取相同评分目标的方差。生成器核对终版源码、模型回执、九项校正和归档方法的指标后才导出全表。
