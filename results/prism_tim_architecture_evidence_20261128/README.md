# Frozen PRISM architecture evidence

本轮绑定 PRISM 提交 7bf849fa0c2453ea58412cc631c3cddf9b6d4e3c 和同一套归档评分行。TEP D=1、SRU H₂S 与 CZ 双棒 H=16 提供消融对照。数值和统计为既有尾段上的机制诊断。终版源码、模型权重、基线权重和主表数值均沿用锁定版本。

## 终版消融

六行表覆盖完整 PRISM、仅水平视图、仅近端 FIR、强制支持域可信度为一、强制放行外生和水平内生状态。三个结构变体只在原合法训练行进行受限重估，保留父模型的正则、曲率参数、包络和 HAC 准入状态。仅水平视图保留完整近端水平滞后。水平内生变体使用等维的过去水平值和同一当前锚点水平项。两个门控变体只切换部署条件。CZ 在零观测延迟时天然只有水平视图。

- SRU H₂S 去掉差分使干净 RMSE 从 0.032818 升到 0.035888。仅 FIR 的干净 RMSE 为 0.030475，低于完整模型。TEP D=1 的 FIR 消融使干净和振荡 RMSE 均上升。
- SRU H₂S 强制可信度为一后，干净 RMSE 改善到 0.031035，振荡 RMSE 从 0.047663 升到 0.909752。TEP 的相应振荡 RMSE 从 0.008706 升到 0.046960。
- 强制放行 Rod1 的外生项使干净 RMSE 从 0.042520 降到 0.041816。该振荡窗 RMSE 相同，输出偏移 MAE 从 0 增至 0.012928。Rod2 对应冻结外生项系数为零，外生放行对两个窗的预测均无影响。

## 冻结权重归因

64 滞后响应是冻结预测器在各视图训练中位点的局部增量响应。计算固定内生状态与单位支持域可信度，同时通过各视图的训练尺度换算回原输入。差分视图经 \(1-B^D\) 合成。排序使用每个传感器一倍训练标准差对应的响应 \(L_2\) 范数。TEP 通道标签来自对应模拟器源文件，SRU 通道身份来自原软测量数据说明。[通道归因](CHANNEL_ATTRIBUTION.csv) · [响应图](IMPULSE_AND_ATTRIBUTION.pdf) · [TEP 源码说明](https://github.com/PSE-Research/Tennessee-Eastman-profBraatz/blob/master/README.md) · [SRU 原始软测量研究](https://www.sciencedirect.com/science/article/pii/S0967066103000790)

SRU 五通道的最大绝对响应出现在 0、1、10、16、18 个采样步，未在 5–9 步出现峰值。展示的是模型局部灵敏度，峰值的物理时间解释还需要独立的时钟和输运证据。TEP 排名前三为汽提塔温度 XMEAS18、压缩机功 XMEAS20 和汽提蒸汽阀 XMV9。34 个原始通道中有 33 个在部署模型中活跃。

故障结束后连续 16 点与干净可信度差不超过 0.01 的首个位置，在 SRU 振荡、TEP 振荡与 TEP 常量偏置中分别为 124、126 和 16 步。图中显示单视图、聚合及干净可信度，并给出 PRISM、ARX 与限幅 Elastic Net 的带符号预测误差。实测恢复曲线及超调统计限于所检查的后续 256 步。[可信度图](FAULT_TRUST_TRAJECTORIES.pdf) · [恢复统计](TRUST_RECOVERY.csv)

TEP XMV12 在训练段为常量。试验向该原始输入施加幅度 100 个输入单位的偏置和振荡，均得到精确零输出偏移。对有非零方差且已剪零的 XMEAS5 水平视图施加 100 倍标准差振荡也得到精确零偏移。CZ 双棒原始加热功率通道的相同审计在其关闭的外生路径下同样为零。SRU H₂S 的全部原始通道活跃。[隔离审计](ZERO_LEAKAGE.csv)

内生水平系数在 TEP 与 SRU 中的范围为 −1.264 至 −0.686，CZ 双棒为 −0.0197、−0.0190。历史开发段滞后审计中，双棒晶升和埚升通道的最强后向关联都落在预测原点之后第 6 步，max-T 校正概率为 0.001。这项相关性证据可与冻结基座的权重分流并列报告，用于区分预测关联和经过识别的因果效应。[水平系数](ENDOGENOUS_LEVEL_COEFFICIENTS.csv) · [开发段滞后审计](CZ_DEVELOPMENT_LAG_AUDIT.csv)

## 固定空间状态与实测延迟

在 Xeon Platinum 8352V 的 CPU 126 上，每个长度和内核测量 131,072 次正式调用。扫频固定 TEP 的原生 PRISM 读出与递推状态，改变 34 通道稠密 ARX 的历史长度。ARX L=64 使用归档权重，较长历史使用附加确定性非零读出项作为计算负载。跨度扫频只比较计算代价。

PRISM 在六个测点的中位耗时为 3.890–4.716 µs。稠密 ARX 从 L=64 的 0.539 µs 升至 L=2048 的 20.828 µs。实测中位和 P99.9 的首个交叉点均为 L=512。端点的 PRISM 状态保持 27,312 B，ARX 从 17,448 B 增至 557,096 B。[跨度图](MEMORY_SPAN.pdf) · [计时明细](MEMORY_SPAN.csv)

TEP D=1 和 SRU H₂S 各连续执行一百万步。每条流以训练周期重复驱动，间隔一万步取 128 个点与最近 4,096 个输入从零状态重放的参考比较。两条流各记录 99 个检查窗，预测、内生基座和可信度的最大绝对差均为零。该数值为给定流与重放参考的实测对比。[长流明细](LONG_STREAM_SUMMARY.csv)

两组代表性部署盘点均覆盖全部九条基线。PRISM 与稠密 ARX、Elastic Net 是实测 C 结构体字节数。其余基线计量持续输入历史，临时推理工作区和静态参数单列或排除在状态列之外。单次训练时间按冻结配置重新测量一条种子，包含特征预处理和拟合，候选搜索和 HAC 嵌套另计。表中分别保留 CPU 与 GPU 设备口径。[部署 LaTeX 表](DEPLOYMENT_COMPARISON.tex) · [部署明细](DEPLOYMENT_COMPARISON.csv)
