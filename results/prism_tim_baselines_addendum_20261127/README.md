# PRISM 投稿补充基线

PRISM 预测来自终版提交 `7bf849fa0c2453ea58412cc631c3cddf9b6d4e3c` 的冻结权重。本轮是对已经评分的尾段补齐对照，E4 继续使用原计时回执。

## 三条新增对照

- **限幅 Elastic Net** 逐通道保存完整训练分区原始传感器的 1% 和 99% 分位。推理时先限幅原始输入历史，再构造原 Elastic Net 的滞后或分块特征。干净与故障回放均启用限幅。成熟标签、模型权重和训练过程沿用归档版本。
- **DPLS** 使用与 ARX 相同的动态特征，回归相对于成熟锚点的目标增量。按折标准化，使用两个后期扩展前向折在 2、4、8、12、16、24 个潜变量中选择，再用全量合格行等权拟合。
- **GRU** 使用与对应 Transformer 一致的因果输入组织方式。TEP 使用分块 DCS 输入和最新成熟标签特征。SRU 和 CZ 使用各自的原始序列长度及成熟标签通道。单层 GRU 在 24、48 宽度和 1–8 个 epoch 中按后期双折池化 MSE 选择，AdamW 学习率为 0.001，批量为 256。公开四组各训练五个种子，CZ 双棒各三个。

新增拟合使用冻结 PRISM 的合格训练行和标签成熟边界。评分沿用原尾段行，CZ 主协议屏蔽相同的重叠目标。故障窗口为尾段首个连续 512 发报点，幅值为四倍训练标准差，仅作用于传感器。Rod1 的压力对照采用与 Rod2 相同的故障构造。CZ 工作簿与模型权重保存在本机。

## 表格口径

干净与故障表均给出集成预测和种子平均误差。输出偏移是相对该模型自己的干净预测。Bartlett HAC 配对 DM 使用平均逐行平方损失，并在每个数据集和工况内对九项比较做 Holm 校正。CZ 排除区间两侧的损失序列保留时间断点。极小概率可读 `log10_p_holm`。
