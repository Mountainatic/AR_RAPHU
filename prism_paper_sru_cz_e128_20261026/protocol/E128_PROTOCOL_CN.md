# CZ 的 E 与128步历史合同

用户于2026-10-26补充：CZ主实验的输入历史应足够长，尽量128步，并通过E表示不同时间尺度。当前主实验据此固定128个历史采样点；E16只作历史长度消融，不进入CZ主模型选择。

“128”表示最大历史支持长度，不表示最细时间分辨率。分辨率由E的采样步长或分箱宽度决定；覆盖范围和分辨率是两个参数。

本次E128使用固定多分辨率分箱：

| 时滞区间，左闭右开 | 宽度（采样步） |
|---|---:|
| [0,1) | 1 |
| [1,2) | 1 |
| [2,4) | 2 |
| [4,8) | 4 |
| [8,16) | 8 |
| [16,32) | 16 |
| [32,64) | 32 |
| [64,128) | 64 |

先对每个过程通道、每个区间求原始历史均值，再构造该通道的幅值样条基，由K/C学习各通道与时滞块的系数，随后经过W与成熟残差A。所有幅值结点、标准化和系数都只从相应训练区间拟合。

最近部分保留细分辨率，较远历史用较粗分箱压缩。E覆盖的输入为X(t),...,X(t−127)；历史目标只能使用y(t−delay),...,y(t−delay−127)。当前y(t)与未来X不可进入模型。

这符合原理论中 `FIXED_MULTIRESOLUTION` 的E类型，但不是完整原版 `CHANNEL_SPECIFIC` profile/rank搜索，也不应把它重标为未经改动的v0.6。

原理论位置：`AR_RAPHU_prism_strict_oof/PRISM_INDUSTRIAL_BENCHMARK_V1/PRISM_V2_MODULAR_NUMERICALLY_FROZEN/PRISM_Theory_v2_0_Modular_Assembly_Theory_Only.md`，第3.1节；原CZ时间profile登记也明确区分history与delta。

本轮比较三条独立训练分支，每条两根棒×3种标签延迟×full/no_A：

1. `fixed128`：样条修正后的现有长历史压缩，作为单历史均值参照。
2. `E128`：上述8个时滞块，CZ主候选。
3. `E16`：同样的编码原则，截到16步，作为短历史重训消融。

同一组比较使用原有相同训练和开发目标日期、共同127+delay依赖隔离、原273项A候选与支持/数值门槛。E128与E16候选数量相同，但输入信息与特征数不同，不声称相同FLOPs或相同参数量。

长历史“有输入”“预测时确实使用”“提高泛化误差”“恢复了物理规律”是不同证据层级。本轮测试前两项和开发期预测收益；不凭128这一数字直接声称恢复工艺机制。
