# 各输入变量能解释多少输出变化

逐变量结果见 [INPUT_ATTRIBUTIONS.csv](results/INPUT_ATTRIBUTIONS.csv)，完整定义与来源哈希见 [INTERPRETABILITY_AND_ROD1_ABLATION.json](results/INTERPRETABILITY_AND_ROD1_ABLATION.json)。使用原始未清理模型与相同开发目标；没有重新拟合归因模型。

模型的上游 ridge 在标准化设计坐标内可逐列精确相加。按变量合并这些项，再用 scalar output link 的割线系数分摊 W 前后的非线性输出变化，最后将 A 补偿单列一项。每个预测满足：常数基准 + 历史目标项 + 五个过程输入项 + A = 完整预测。割线分摊是一个明确但非唯一的约定。

设某组输出项为 g_j，完整预测为 p，则该组分配的 R² 点数为：

`100 * (2*Cov(y,g_j) - Cov(p,g_j)) / Var(y)`。

加上均值偏差项 `-100*(mean(y)-mean(p))²/Var(y)` 后，各项严格加总到 `100*R²`。因此可出现负数，不能把各项当成彼此独立、非负且总和为 100% 的物理解释比例。

CSV 同时给出训练中心遮蔽敏感性：将某组标准化设计特征置为训练中心，重新经过 W 并重放冻结 A，比较 RMSE。它没有重新训练、没有对真实工况实施干预，不能解释为变量的因果贡献。A 项也是利用成熟标签的模型校正项，不是额外物理传感器。

变量共线、闭环控制、工况外推及目标持续性都会影响分配。Rod2/d16 的总 R² 为负，归因项相互抵消很大，这应作为模型失配的诊断，不能据大贡献值宣称强物理机制。原始过程轨迹与逐点贡献未公开。
