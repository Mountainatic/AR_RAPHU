# PRISM v0.8 冻结核验与同级 SIMD 计时

在指定的 westb 服务器完成统一入口、模型与基线权重核对、最后一次开发评分和同级 SIMD 计时。v0.8 的 SRU 改善，Rod1 与 Rod2 相对 v0.7.1 退化。Rod2 同时失去对扩展 Transformer 五次均值的优势。按本轮要求，保留尾段评分停在开发核验之后，未读取任何一套尾段的观测值。

## 统一算法

时钟协议固定为 (H=0,D=4,L=128)。每次 issue 只读截至 (t) 的过程量和截至 (t-4) 的真值。开发行分别为 `[6048,8064)`、`[12061,16082)` 和 `[12376,16501)`。

自然基的最外节点绑定训练分位数 5% 与 95%。两种收缩档位都在同一训练入口产生，使用相同的早期训练折和 K–C–W–A 拟合流程。单通道稳健档的每行岭惩罚基准网格为 (10^{-9},10^{-7},10^{-5},10^{-3},0.03)。融合保真档保留到 (10^{-5})。两档都允许逐视图从近端 4 或 8 步中选择，按训练行数换算惩罚，保留曲率矩阵。后续四个校准块的 KCWA 配对风险决定是否采用融合保真档。门控要求至少三块改善且均值超过半个块间标准误。C、W 继续使用活跃权重可信度，A 各家族分别投票。

固定双档入口消除了分实体套用补丁的实现。收缩档位和 5%–95% 边界依然来自此前的开发探索。本轮将这些决定在新开发评分前登记、拟合并封存。评分后未更改模型、阈值和网格。

## 公平原生 C 计时

稠密 ARX 采用逐通道镜像环，冻结标准化尺度折入权重。向量版用 AVX2/FMA 与四条独立累加链计算全部 768 个 FP64 系数。PRISM 和 ARX 标量 C 同用 GCC `-O3 -ffp-contract=off`，SIMD 版同时加 `-mavx2 -mfma -funroll-loops`。两种模式都在同一 Xeon Platinum 8352V 的核心 64 实测同一批真实开发行，各配置交错执行 30 次。计时含标签成熟、模型状态更新和结果写回，前缀预热在计时窗口外。

AVX2/FMA 同级比较中，v0.8 的 Rod1 相对 ARX 约快 1.28 倍，Rod2 接近持平，SRU 耗时约为 ARX 的 2.47 倍。上轮以旧 ARX 内核为分母得到的速度倍比不能用于同级结论。六种实现共十八组回放均通过逐点预测核对和未来输入/未成熟标签前缀检查，最大绝对误差为 (1.14	imes10^{-13})。计时明细保存了 30 次原始样本和 P95。
