# PRISM Tanks + CZ supplementary E1-E6

This package is an auditable supplementary execution record based on the
strict-OOF authority branch. Tanks E1 is the frozen H16/64-second result;
corrected Tanks E2–E6 are under `TANKS_H16_CORRECTED_R3/`. The original
`TANKS/E2_*` through `TANKS/E6_*` files are retained only as superseded audit
history because their runner used an 8-second target.

For CZ, the current primary evidence is raw-2s L256 with H4/W1/W0=1. The
included older D20 evidence is historical-only and cannot be mixed with the
raw-2s ranking. Private raw workbooks are not included.
