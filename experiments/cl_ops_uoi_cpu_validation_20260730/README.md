# CL-OPS-UOI CPU 跨晶棒验证

本分支保存针对两根直拉硅晶棒闭环生产数据的 **锚定增量 K 层验证**代码与可审计结果。

## 核心问题

为避免强 AR 历史覆盖控制变量信息，主模型仅使用当前直径 `y(t)` 作为锚点，预测

\[
\Delta_h y_t = y_{t+h}-y_t.
\]

不把 `y(t-1), y(t-2), ...` 输入 K 层。控制历史负责解释未来直径增量。

## 变量协议

控制变量：

- 主加热功率
- 晶升速度
- 晶转速度
- 埚升速度
- 埚转速度

输出变量：晶体直径。

晶体长度、加热元件温度、氩气流量、炉压不进入主辨识支路。

## 数据边界处理

以 `|Δ直径| > 0.20 mm` 识别硬边界：

- Sheet1：334、688、734
- Sheet2：745

不插值、不平滑连接，任何历史窗口不得跨越边界。主验证使用最后一次边界之后的稳定连续段。原始 XLSX 数据未提交到仓库或发布包。

## 主要结果

在 `h=15, L=128, R=32` 下：

| 候选方向 | 训练→测试 | 线性时滞核 MSE 改善 | 95% block-bootstrap 下界 | 非线性 K 相对线性核 |
|---|---:|---:|---:|---:|
| 晶升 | Sheet1→Sheet2 | 13.25% | 10.15% | -2.94% |
| 晶升 | Sheet2→Sheet1 | 13.31% | 9.13% | -3.10% |
| 联合升速 | Sheet1→Sheet2 | 13.50% | 10.32% | -3.17% |
| 联合升速 | Sheet2→Sheet1 | 13.61% | 9.61% | -0.03% |

两个训练方向恢复出的晶升线性核相关系数为 `0.96288`。1000 次 block-bootstrap 中，线性时滞核改善为正的比例均为 100%。

## 解释边界

当前结果支持：

- 升速控制族存在跨晶棒可迁移的线性时滞预测结构；
- 该结构不是当前控制量的简单静态映射；
- 完整幅值依赖非线性 `K(τ,u)` 尚未稳定优于线性时滞子模型。

由于晶升与埚升高度共线，目前不能把两者解释为独立因果通道。结果属于自然闭环数据下的预测核证据，不等同于开环物理传递核。

## 复现

脚本：`src/cl_ops_uoi_final_run.py`

脚本当前使用 ChatGPT 数据处理环境中的 `artifact_tool` 读写 XLSX，并依赖：

- Python 3.10+
- NumPy
- SciPy
- Matplotlib
- artifact_tool

默认输入路径写在脚本顶部。运行前修改 `IN` 与输出路径即可。

```bash
python src/cl_ops_uoi_final_run.py
```

## 分支内容
