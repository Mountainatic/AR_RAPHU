# R3 compact evidence

This directory contains the compact, Git-tracked evidence for the completed frozen-predictor NeuroBEM R3 audit. Full per-anchor perturbation curves remain on the server at the paths and SHA256 values in `FULL_EVIDENCE_POINTERS.json`; they are intentionally omitted from the small return bundle. No raw/processed NeuroBEM data or prediction archive is included.

The held-out test was accessed once after calibration evidence was frozen and committed. It was not used for tuning.
